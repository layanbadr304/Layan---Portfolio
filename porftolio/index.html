Rawiyah

Arabic NLP & Saudi cultural heritage storytelling

Rawiyah is an intelligent cultural platform that preserves and presents Saudi heritage and national identity through interactive Arabic storytelling — covering historical figures, places, events, and traditional expressions. It was deliberately designed to feel like a guided narrative experience, not a chatbot.

PROBLEM
Saudi cultural and historical knowledge is scattered and rarely presented in a way that's both accurate and engaging for a general Arabic-speaking audience.
SOLUTION
A source-grounded retrieval system paired with Arabic text-to-speech, presenting only information traceable to trusted references, wrapped in an interactive storytelling interface rather than a Q&A format.
MY CONTRIBUTION
Designed the NLP pipeline and knowledge base structure, built the source-grounded retrieval logic, and shaped the storytelling interaction model end-to-end.
RESULT / IMPACT
A working prototype that surfaces Saudi cultural knowledge through a narrative interface distinct from typical chatbot UX.

OpsMix-Ar

Arabic–English LLM agent evaluation in executable infrastructure environments

A research project evaluating how robust LLM agents are when executing real infrastructure and sysadmin tasks across English, Modern Standard Arabic, Gulf Arabic, and mixed Arabic–English input — using a benchmark of 500 executable tasks against 8 models.

PROBLEM
Most agent benchmarks evaluate task success in English only, leaving it unclear whether tool-calling agents stay safe and reliable when instructions arrive in Arabic dialects or code-mixed language.
SOLUTION
Built an executable evaluation environment — service restarts, log inspection, deployment rollback, replica scaling, API key rotation, and configuration changes — and ran 8 LLMs against 500 tasks across four language varieties, scoring tool calling, action sequencing, and safety.
MY CONTRIBUTION
Designed the multilingual task set and executable tool environment, ran the evaluation pipeline across all 8 models, and analyzed robustness and safety failures by language variety.
RESULT / IMPACT
Findings were written up as a research paper on multilingual robustness of LLM agents in infrastructure settings.

AmanPlay

Deep learning & NLP for digital safety

A digital safety project detecting harmful and toxic content using Arabic NLP and deep learning, combining AraBERT with CNN and LSTM architectures for content moderation.

PROBLEM
Toxic and harmful content in Arabic text is harder to detect reliably than in English due to limited tooling and dialectal variation.
SOLUTION
A classification system combining AraBERT embeddings with CNN and LSTM layers to identify and moderate toxic content with high accuracy.
MY CONTRIBUTION
Built and trained the classification models and contributed to the overall moderation system design.
RESULT / IMPACT
Won 1st place at Thakaathon.
